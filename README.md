# Custom-Table-Maintenance-Tool
A Single Module Pool Application to Display, Insert, Update and Delete Records of Any Custom Tables[Z-Tables].

<--------- 31-10-2026 --------->
**Before You Use This Application**

Hi, and thanks for visiting!

Before downloading, copying, or using this application in your SAP system, please take a few minutes to read this document completely.

This application, Custom Table Maintenance Tool, started as a fun side project and an experiment to explore dynamic programming techniques in ABAP.

**What does this application do?**

The application allows you to perform CRUD operations (Create, Read, Update, and Delete) on custom tables in your SAP system through a single program.

**Known Issues and Limitations**

Please be aware that this is an experimental project and is not yet production-ready. There are a few known bugs and limitations, particularly related to:

Navigation within the application.

Updating date and time fields.

There may also be other issues that I haven't identified yet.

**Important: Read Before Using**

**There are two important limitations you should be aware of:**

**No Authorization Checks:** No authorization objects or authorization checks have been implemented to restrict access to the application's functionalities. Users who can execute the program may be able to perform operations on custom tables without proper authorization restrictions.

**No Change Logs:** The application does not maintain any logs or audit trails for data modifications. Changes made through this application will not be recorded by it.

Please do not use this application in a production environment or with business-critical data in its current state. Understand its structure, limitations, and potential risks before experimenting with it in your system.
